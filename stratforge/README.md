# ◆ StratForge

**Strategy & Consulting Decision Lab**

StratForge is an interactive consulting workbench built to demonstrate structured problem solving, quantitative analysis, and executive communication. It turns a synthetic business case into a market-entry recommendation, profitability scenario, competitive positioning view, and board-style recommendation memo.

## What it demonstrates

- Issue-tree thinking and MECE-style problem structuring
- Market attractiveness scoring and prioritization
- TAM-based market sizing
- Profitability decomposition and scenario analysis
- Competitive benchmarking
- Investment payback and three-year value modeling
- Executive recommendation synthesis

## Tech stack

`Python` · `Streamlit` · `Pandas` · `NumPy` · `Plotly`

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Why this project matters

Consulting work is not just about making charts. The value comes from structuring an ambiguous problem, identifying the few variables that matter, quantifying tradeoffs, and communicating a clear recommendation. StratForge was designed around that workflow.

## Portfolio note

All case data is synthetic. The application is intended to demonstrate strategy, analytics, scenario modeling, and business communication skills rather than represent advice for a real company.
